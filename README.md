# UseNohl E-commerce

UseNohl é uma experiência de e-commerce front-end para uma loja de roupas e acessórios, criada com foco em navegação simples, identidade visual consistente e recursos interativos que simulam uma jornada real de compra.

O projeto foi desenvolvido como primeiro projeto front-end após a conclusão de estudos em HTML, CSS e JavaScript, reunindo catálogo de produtos, carrinho, autenticação local, perfil de usuário e pré-checkout em uma aplicação estática.

## Visão Geral

A proposta da UseNohl é apresentar uma loja digital leve, responsiva e direta ao ponto. O usuário pode navegar por categorias, adicionar produtos ao carrinho, alternar entre tema claro e escuro, criar uma conta, acessar seu perfil e seguir até uma etapa de revisão da compra.

Embora seja um projeto acadêmico e demonstrativo, a estrutura foi pensada para representar fluxos comuns de um e-commerce real.

## Funcionalidades

- Página inicial com produtos em destaque e chamada para ofertas.
- Catálogo dividido por categorias: blusas, calças e acessórios.
- Carrinho de compras com controle de quantidade, remoção de itens e subtotal.
- Pré-checkout com resumo do pedido, cupom de desconto e opções de garantia.
- Sistema de login e cadastro usando `localStorage` e `sessionStorage`.
- Perfil de usuário com dados cadastrados.
- Alternância entre modo claro e modo escuro.
- Interface responsiva para desktop, tablet e dispositivos móveis.

## Tecnologias Utilizadas

- HTML5 para estrutura das páginas.
- CSS3 com variáveis, Flexbox, Grid e media queries.
- JavaScript puro para interações, carrinho, autenticação e persistência local.
- Web Storage API para simular estado de usuário e carrinho.
- BoxIcons para ícones da interface.

## Diferenciais do Projeto

- Fluxo completo de navegação, cadastro, carrinho e checkout demonstrativo.
- Interface com tema claro e escuro persistente.
- Organização visual voltada para uma loja de moda.
- Implementação sem frameworks, reforçando fundamentos de front-end.
- Projeto leve, executável diretamente no navegador.

## Como Executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Navegue pelas categorias, adicione produtos ao carrinho e teste os fluxos de login, cadastro e checkout.

Também é possível executar pelo VS Code usando as configurações de debug disponíveis em `.vscode/launch.json`.

## Estrutura Principal

- `index.html`: página inicial da loja.
- `blusa.html`, `calca.html`, `acessorios.html`: páginas de categoria.
- `login.html` e `cadastro.html`: autenticação e criação de conta.
- `meuperfil.html`: visualização de dados do usuário.
- `checkout.html`: revisão e finalização demonstrativa da compra.
- `style.css`: estilos globais, responsividade e temas.
- `script.js`: lógica de carrinho, usuário, tema e interações.

## Aprendizados

Este projeto consolidou conceitos essenciais de front-end, incluindo manipulação do DOM, armazenamento local, componentização visual por repetição de padrões HTML/CSS, responsividade e criação de fluxos de interface com JavaScript puro.
